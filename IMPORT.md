## Method 1 — MySQL CLI (recommended)

```bash

```

### From compressed file


### Schema first, then data


## Method 2 — Docker (new container)

```bash
# Start a fresh MySQL 8 container
docker run -d \
  --name rfihunter-new \
  -e MYSQL_ROOT_PASSWORD=root_secret \
  -e MYSQL_DATABASE=rfihunter \
  -e MYSQL_USER=rfihunter \
  -e MYSQL_PASSWORD=rfihunter_pass \
  -p 3307:3306 \
  mysql:8.0

# Wait for it to be ready (~10 seconds), then import
docker exec -i rfihunter-new mysql -uroot -proot_secret < rfihunter_full.sql

# Verify
docker exec rfihunter-new mysql -uroot -proot_secret rfihunter \
  -e "SELECT COUNT(*) as tenders FROM tenders;"
```

## Verifying a successful import

Run these queries after import:

```sql
USE rfihunter;

-- Row counts
SELECT 'tenders'       AS tbl, COUNT(*) AS rows FROM tenders
UNION ALL
SELECT 'scrape_runs',  COUNT(*) FROM scrape_runs
UNION ALL
SELECT 'industry_areas', COUNT(*) FROM industry_areas
UNION ALL
SELECT 'locations',    COUNT(*) FROM locations;

-- Sample RFI notices with contact info
SELECT id, type, title, buyer_email, buyer_phone,
       JSON_LENGTH(pdf_urls) AS pdf_count,
       opportunity_score
FROM tenders
WHERE buyer_email IS NOT NULL
ORDER BY opportunity_score DESC
LIMIT 5;

-- Open tenders with PDFs
SELECT COUNT(*) AS open_with_docs
FROM tenders
WHERE status = 'OPEN' AND pdf_urls IS NOT NULL;
```

## Notes

- **Character set**: `utf8mb4` with `utf8mb4_unicode_ci` — required for Finnish characters (ä, ö, å).
- **MySQL version**: Dump was generated by MySQL 8.0. Compatible with MySQL 8.0+ and MariaDB 10.6+.
- **JSON columns**: `cpv_codes`, `keywords`, `pdf_urls`, `raw_data` use MySQL native JSON type.
- **Full-text index**: `tenders(title, description)` — enables `MATCH … AGAINST` search in the API.
- **Foreign keys**: Disabled during import (`SET FOREIGN_KEY_CHECKS=0`) and re-enabled after — safe to import in any order.
